# DecodeLabs Data Science Internship

A collection of Data Science projects completed during my remote internship at DecodeLabs.

## Overview

During this internship, I worked on practical Data Science projects covering exploratory data analysis, feature engineering, supervised machine learning, and unsupervised learning.

The projects demonstrate different stages of a typical Data Science workflow, from data exploration and preprocessing to model development, evaluation, and interpretation.

## Projects

### Project 01 — EDA & Feature Engineering

Exploratory data analysis and feature engineering using the Titanic dataset.

**Focus:**
- Data cleaning and preprocessing
- Exploratory data analysis
- Numerical and categorical feature analysis
- Data visualization
- Feature engineering

---

### Project 02 — Credit Card Approval Prediction

A supervised machine learning project focused on predicting credit card approval outcomes.

**Focus:**
- Exploratory data analysis
- Data preprocessing
- Categorical encoding
- Feature scaling
- Logistic Regression
- Random Forest
- Model evaluation and comparison

---

### Project 03 — Customer Segmentation

An unsupervised machine learning project focused on identifying customer segments from demographic, purchasing, and campaign-response data.

**Focus:**
- Data preprocessing
- Feature standardization
- Principal Component Analysis (PCA)
- K-Means clustering
- Elbow Method
- Silhouette Score
- Customer segment analysis
- Business-oriented customer personas

---
