\# 💳 Project 2: Credit Card Approval Prediction



\## Decode Labs Data Science Internship



\---



\# 📌 Project Overview



This project develops machine learning classification models to predict whether a credit card application should be approved based on applicant information.



The project demonstrates a complete end-to-end supervised machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature encoding, feature scaling, model training, evaluation, and comparison.



\---



\# 🎯 Objectives



\- Understand the dataset

\- Perform data preprocessing

\- Handle missing values

\- Encode categorical variables

\- Scale numerical features

\- Train multiple classification models

\- Evaluate model performance

\- Compare machine learning algorithms



\---



\# 📊 Dataset Information



\- Dataset: Credit Card Approval Dataset

\- Records: 690

\- Features: 16

\- Target Variable: Approved

\# 📊 Model Performance



| Model | Accuracy |

|--------|----------|

| Logistic Regression | 83.33% |

| Random Forest | 85.51% |



Random Forest achieved the highest prediction accuracy and outperformed Logistic Regression on this dataset.
